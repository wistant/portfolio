**ZaDark** is a premium browser extension and developer tooling kit that adds Dark Mode, advanced anti-peeking privacy features, custom typography, and personalized background adjustments to Zalo Web and Zalo PC.

The extension was built to address a major user experience gap, providing an elegant dark mode and highly needed privacy controls for daily communication.

<br />

### Key Achievements & Metrics

- **Paid Safari Extension:** Earned 10M+ VND in net sales directly via the Apple App Store.
- **SourceForge Community Leader:** Acquired 80k+ downloads on SourceForge, earning the prestigious _Community Leader_ badge.
- **Chrome Web Store:** Attracted 30k+ active daily users.
- **Bronze Medal:** Awarded the Bronze Medal at the 10th Design, Manufacturing, and Application Award (2022).

<br />

### Core Features

- **Dynamic Dark Theme:** Intelligently maps colors and applies consistent dark styling without causing layout flickering or blinding white flashes.
- **Anti-Peeking Privacy Shield:** Blurs messages, contacts, and images until hovered, protecting sensitive chats in public or workspace environments.
- **Font & Background Engine:** Empowers users to customize chat container fonts and add high-resolution background images.
- **Performance Optimized:** Extremely low memory footprints and zero background script bloat to ensure the host browser remains ultra-fast.

<br />

### Technical Architecture

- **Extension Framework:** Built using Manifest V3 for secure, modern browser integration across Chromium-based browsers (Chrome, Edge, Brave, Opera) and WebKit (Safari).
- **Core Engine:** Written in pure, highly-optimized JavaScript utilizing DOM mutation observers and efficient style injection pipelines.
- **Documentation Site:** Built using Docusaurus 3 for absolute search indexing, localization, and technical blogging.
